## Confirmed actionable finding

### C1 — FIX — MEDIUM: raw disk differences can pass with no committable implementation change

**Location:** `skills/work/scripts/check_qwen_output.py:60`–64 and `:112`–115.

`worktree_changed()` compares executable bits and `git hash-object --no-filters` to the committed blob. The same comparison is used for both Tess integrity and the implementation no-edit decision. Raw disk inequality is stronger than Git's definition of an implementation diff: newline normalization and ignored executable bits can erase it when step 5 stages the path.

Two independent disposable repositories reproduced the failure:

| Fixture | Qwen-equivalent output | `before` | `after` | After path-scoped `git add impl.py` |
|---|---|---|---|---|
| `.gitattributes`: `impl.py text eol=lf`; committed `answer = 0\n` | Rewrites identical text as `answer = 0\r\n` | exit 0 | exit 0, `{"arm":"pass","next":"proceed","cause":null}` | `git diff --cached --name-only -- impl.py` is empty |
| `core.filemode=false`; committed nonexecutable `impl.py` | Changes only its mode to `0755` | exit 0 | exit 0, same pass verdict | Same empty staged diff |

Each repository contained an unchanged committed Tess test, a clean implementation baseline, local fixture identity, disabled fixture hooks/signing, and no application changes. Thus the difference is not caused by foreign work, stale snapshots, or an invalid baseline. Both fixtures were removed by `TemporaryDirectory` cleanup.

**Impact:** SKILL step 4 interprets exit 0 as permission to enter step 5. Step 5 stages and attempts a commit despite there being no implementation change to commit, instead of recording `qwen_no_edit` and selecting Sonnet. This violates the PRD's task-scoped no-edit/empty-commit acceptance criterion.

**Bounded fix:** distinguish the implementation's committable Git diff from the raw disk/index comparison required for immutable Tess tests. Preserve the direct disk checks that defeat `assume-unchanged`/`skip-worktree`; do not weaken the test oracle to solve the implementation detector. Add focused regression fixtures for normalized newlines and ignored mode changes, both expecting `qwen_no_edit`, no staging/commit by the guard, and `next: "sonnet"`. Any comparison requiring index refresh or filters must preserve the live index and foreign work.

**Action taken:** reproduced both cases and sent the location, outputs, impact and fix boundary to the parent. No source edit was made under the explicit read-only assignment.
