## 1 of 21 - HIGH - review-close applies a batch that gate refuses

**What.** At the decision gate the loop runs only `review-close`, never `gate --findings` (`references/phase-review.md`). When the review file's findings heading is spelled slightly differently (`## Consolidated findings`, `### Consolidated Findings`, `## Consolidated Findings (cycle 2)`) or missing, `gate` refuses but `review-close` applies the batch anyway, creating no task for a CRITICAL row. Found by trudy (security) and wendy (release truth: CHANGELOG line 14 says review-close "now refuses exactly what gate refuses").

**Evidence (confirmed).** Same file, Ref table with R1 🔴: `gate` exit 1 "no '## Consolidated Findings' section in the review file"; `review-close` exit 0 `{"applied": true, "tasks_created": [], ..., "findings_cross_check": "malformed"}`, and the unbacked R2 defer row was applied with no backing check. A file whose only CRITICAL sits under `## Alice` with findings `[]`: `review-close` exit 0, lenses closed. Same on 0.9.0. The code calls the no-section case "Surfaced, never refused" on purpose (legacy files).

**If unchanged.** A model-written review with a heading typo carries a CRITICAL out of the run with no task and no refusal. Likely enough: heading wording is model-generated every cycle. Stays stable, but each occurrence lands silently.

**Options.**
1. **(Recommended) Refuse the no-section verdict in `review-close` whenever the file holds any `[m/n]` consensus token or a table row, or `--findings` is non-empty; keep "surfaced" only for a truly empty legacy file.** Benefit: closes the class without loosening the heading match. Drawback: a legacy review with findings now needs a rewrite to close. Effort S. Could break: legacy-file tests that expect `malformed` to apply. Strongest reason against: it adds a second, looser "does this look like findings" check beside the parser.
2. Match the heading case-insensitively at any level (`#{2,3}`, optional suffix) in both verbs. Benefit: the variants trudy used parse normally. Drawback: a wholly missing heading still applies. Effort S. Could break: files with a quoted heading in prose.
3. Run `gate --findings` before `review-close` in phase-review prose and the close verb. Benefit: one source of truth. Drawback: two calls per cycle; prose-only enforcement can drift. Effort M.
4. Accept or defer.

**If unchanged.** Only bites when two closes race (a retried call, two sessions), and then only matters if someone needs the backup. Low likelihood, stable.
