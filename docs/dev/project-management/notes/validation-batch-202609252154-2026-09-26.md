## Findings (V1..V9)

- **V1 Interactive mode is the wrong host for this pipeline.** Four subagents stalled
  on permission prompts (Tess ×2, Devon, Ivan on task 1), each detected only by the
  15-min watchdog plus a 10-min second probe: ~67 min lost on one task. Headless
  `autoclaude` has no prompts; the fix is operational (run batches under the loop),
  plus a `/warden:allow` set for the pack's helper scripts when a build must be
  interactive.
- **V2 Devon never survives round 2.** 4/4 tasks: round 1 found an exploit, Tess
  strengthened, round 2 found another and the round was exhausted. Round 1 produced
  three real pins (payload cwd + walk-up, cap boundary, exact python3 command/type/
  timeout); round 2 produced nothing kept (8 dispatches, ~26 min wall, ~0.5M tokens).
  Consider dropping the re-check dispatch (keep strengthen-once) or gating it on the
  round-1 exploits being in-contract.
- **V3 The Devon prose gate keys on basename, not content.** Task 4's docs pin lives in
  `test_guard_stop_on_live_lanes.py`, so two Devon rounds ran on a substring pin that
  "cannot see negation" by construction (the gate's own rationale). Gate on the test's
  reads (a test that reads `SKILL.md` is a prose pin) or on a task-level flag.
- **V4 Pat breaks his own reporting contract 3 times in 4.** Tasks 1, 2 and 4 needed the
  correction retry because the first reply opened with a prose line starting
  `CLOSURE ... not applicable`. The persona's "Closure verdicts (only when ...)" section
  invites the announcement. One sentence in `agents/pat.md` ("with no findings block,
  emit no CLOSURE line and do not mention it") removes a systematic extra dispatch.
- **V5 Per-dispatch boot floor dominates tokens.** A de-slop agent that made 2 tool calls
  and found nothing cost 58.6K tokens; every opus subagent starts at ~55-60K. 21 opus
  Agent dispatches for 4 small tasks ≈ 1.2M tokens of boot inside ≈ 1.58M total. The
  lever is dispatch count per task (8 here: tess, devon, tess, devon, ivan, deslop,
  pat, pat-retry), not prompt size (prompts were 4-26 KB).
- **V6 Full pipeline on a config task.** Task 3 (register one hook, add one test file to
  release-checks) classified `opus/contract`, so Devon and the full depth ran on a
  7-line manifest diff. A config-only implementation slice could take the lean
  pipeline even when a test edit accompanies it.
- **V7 Review session orientation.** First 4 min of the review session: 12 reference and
  persona file reads, `gather-context` run twice (first over the wrong range, then
  "Regather context over the PRD work range"), two failing `engram` probes (not
  installed; not a registered repo) that fail every cycle. Short-circuit the engram
  probe when the binary is absent, and pass the range to gather-context once.
- **V8 Formatter reflow churn.** loupe re-wrapped the edited test modules at the end of
  every subagent turn; five reverts (`git checkout` or hand-restore) were needed to keep
  the reflow out of the commits. Either exempt `hooks/*.py` and `skills/**/test_*.py`
  from loupe's end-of-turn pass in this repo, or accept the formatter's style once.
