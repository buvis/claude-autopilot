`{OUTPUT_FORMAT}` is:

Each issue on its own line, exactly:

```

```

Severity emojis: 🔴 Critical, 🟠 High, 🟡 Medium, ⚪ Low.
One issue per line. Use `N/A` for file when the issue is architectural or
cross-cutting; use `general` for task when it spans tasks or is a PRD gap.

across reviewers on file path, and an absolute path breaks the match.
